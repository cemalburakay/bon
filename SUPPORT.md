# Support

Bon is a small, pre-release, Windows-first personal project with no paid support or response-time guarantee.

- For reproducible defects, use the repository's **Issues** tab and the bug report form.
- For proposed behavior, use the feature request form.
- For setup and commands, read [SETUP-GUIDE.md](SETUP-GUIDE.md) and [USER-GUIDE.md](USER-GUIDE.md).
- For security reports, follow [SECURITY.md](SECURITY.md), not a public issue.

Before posting, redact prompts, private URLs, usernames, access tokens, and local file paths. Do not upload model weights, setup archives, or unreviewed server logs.
